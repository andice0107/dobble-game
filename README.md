# 數位塔寶遊戲 Dobble Game

單一 HTML 教室遊戲，雙擊即玩、離線可用（本頁另可透過 GitHub Pages 線上玩）。

- 線上玩：https://andice0107.github.io/dobble-game/
- 本機玩：下載 `index.html` 後用瀏覽器開啟即可。

## 玩法

兩張卡片中只有 1 個相同圖案，找到就點一下搶答。

## 兩種模式（設定頁切換）

- **一般模式**：學生自己點答。限時內只有「放棄這題」可按；時間到未答「下一組」才亮；不限時採兩段式（放棄 → 下一組）。
- **🎤 主持人模式**：設定參賽者名單（每行一位），寬螢幕左右兩側顯示計分板（＋1／−1），窄螢幕按「📋 計分」浮層查看。按鍵只有看解答／暫停／下一組；開倒數→時間到才能按看解答，沒開倒數→隨時可按；看解答秀出後下一組才亮。結算頁顯示排名。

## 其他功能

- 每張卡元素數、圓形／正方形卡、秒數、組數、錯題上限、emoji／數字／A-Z／注音／自訂文字／上傳圖片元素、⏸ 暫停霧化（計時跟著停）。
- 純前端，無後端、無帳號、無個資收集。
